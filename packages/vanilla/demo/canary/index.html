Choose by lifespan

The path decision comes before component selection.

Recommended for one-offs

Path A · Vanilla HTML

Use for a single page or disposable artifact. It opens directly in a browser and uses readable ax-* classes, native controls, and no bundler.

Long-lived repository app

Path B · React + Next.js

Use the supported React packages when the app will live in a repository, evolve over time, and needs a framework build.

Alternative

Build-less React

For a single-file React experiment, generate an import-map recipe that keeps one React instance. 

npx --yes @astryxdesign/cli@vanilla-poc template --cdn > index.html
